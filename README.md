# Tatjana Žegarac Čorić

This repository contains the personal portfolio website for Tatjana Žegarac Čorić.

## Overview

The main content is in [tatjana.md](tatjana.md), which includes:

- **Hero Section**: Introduction with name and subtitle
- **About Section**: Personal background and information
- **Experience Section**: Professional experience and skills
- **Styling**: Custom CSS with dark theme and gradient effects

## Features

- Responsive design with mobile viewport support
- Dark theme with elegant gradient styling
- Clean typography with custom color palette
- Multiple content sections

## Color Palette

- Primary Background: `#041226` (Dark Navy)
- Light Text: `#F4F1EA` (Off-white)
- Accent: `#AEB7C4` (Steel Blue)
- Secondary Background: `#071B34` (Navy Blue)

## How to View

Open [tatjana.md](tatjana.md) in a browser to view the portfolio, or use a markdown viewer that supports HTML rendering.
